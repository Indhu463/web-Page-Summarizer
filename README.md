# web-Page-Summarizer
# Installation
To install and run this extension locally, follow these steps:
# 1.Clone the Repository:
   git clone https://github.com/your-username/gemini-page-summarizer.git
# 2.Load the Extension in Chrome:
   Open your Chrome browser and navigate to chrome://extensions/.
   Enable "Developer mode" using the toggle switch in the top-right corner.
   Click on the "Load unpacked" button and select the directory where you cloned the repository.
# 3.Add Your Gemini API Key:
  Once the extension is loaded, click on its icon in the Chrome toolbar.
  You will be prompted to enter your Google Gemini API key. You can obtain a free key from Google AI Studio.
  Enter your key and save it.
